⚙ Configuración inicial

Conecta Google Sheets como base de datos. Solo necesitas hacer esto una vez por navegador.

1. Crea un Google Sheet vacío en tu cuenta
2. Ve a Extensiones → Apps Script
3. Borra el código por defecto y pega el contenido de apps_script.js
4. Clic en Implementar → Nueva implementación
    Tipo: Aplicación web · Ejecutar como: Yo · Acceso: Cualquiera
5. Copia la URL del Web App y pégala abajo
